# Shared Utilities

> This document describes the complete workflow. The scripts it names will be added when the paper is
> published.

Shared scripts that are not owned by a single stage.

- `minimal_io.py`: shared JSON, config, output-root, and small geometry helpers.
- `physical_constraints.py`: shared physical and engineering constraint checks.
- `blender_render.py`: Blender rendering helpers for massing and envelope previews.
